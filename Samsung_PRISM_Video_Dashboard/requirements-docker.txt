# =====================================================================
# LEAN, CPU-ONLY deps for the Docker image.
# =====================================================================
# Contains ONLY the packages the inference path actually imports (verified
# by grepping src/ for third-party imports) plus the dashboard's web layer.
#
# Deliberately EXCLUDES the video module's training-only / notebook deps
# (mlflow, jupyterlab, ipykernel, mediapipe, captum, seaborn) and unused
# entries (av, pandas, scipy). Installing the full requirements.txt in
# Docker pulled CUDA packages + backtracked through ~20 torch versions
# (facenet needs torch<2.3) and timed out on an 86 MB download. This
# avoids all of that.
#
# torch + torchvision are installed SEPARATELY in the Dockerfile from the
# PyTorch CPU index (smaller wheels, no CUDA). facenet-pytorch pins
# torch<2.3, so we use the same 2.2.2 / 0.17.2 pair the native venv uses.
# =====================================================================
