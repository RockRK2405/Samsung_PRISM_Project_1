# `src/models`

**Purpose.** Neural network architectures used by the video detection
module.

Planned architectures (not yet implemented):

- CNN baselines (XceptionNet, EfficientNet family).
- ViT-based per-frame feature extractors.
- Dual-stream (RGB + frequency-domain) backbones.
- Temporal heads (LSTM, cross-frame attention).
- Full end-to-end detectors composed from the above blocks.
